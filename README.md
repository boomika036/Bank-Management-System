# Bank-Management-System

A simple **Banking System** project developed to manage basic banking operations through a user-friendly application.

## Features

* Create a new bank account
* Deposit money
* Withdraw money
* Check account balance
* View account details
* Transfer money
* Exit the system

## Technologies Used

* Java
* Git & GitHub

## Project Type

Console-Based Application

## Purpose

This project is created to understand and implement basic banking operations using **Java programming concepts**.

## Future Enhancements

* Transaction history
* Login authentication
* Database connectivity
* Admin dashboard
